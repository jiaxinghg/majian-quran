# majian-quran

马坚译《古兰经》中文全译本全文库（Agent Skill）。

- **内容**：114 章、6236 节完整译文全文
- **结构**：`chapters/p001.md` ~ `chapters/p114.md`（章号与《古兰》章序一一对应）
- **辅助文件**：`glossary.md`（译名与术语）、`patterns.md`（译文结构模式）、`cheatsheet.md`（114 章速查表）
- **入口**：`SKILL.md`

## 用法

按章检索：确定章号 → 读 `chapters/pNNN.md` → 定位节号。引用格式「pNNN」（章）、「章号:节号」（节，如 2:255）。

## 数据说明

- 全文源自马坚《古兰经》中文译本（汉译通行本，1906–1978）。
- 源文件为 DOCX；节号排版变异（破折号编号、无标点编号、重复编号、漏零等）与少量 OCR 噪声已在生成时修正，详见 `patterns.md`「节号标记模式」与「OCR 噪声修正记录」。
- 章节属性（麦加/麦地那）与节数取自每章题下标注，已逐章校对。
